## Intake

- Use the [session intake checklist](session-template.md) before processing notes.
- Copy the [detailed session template](../templates/session.md) into `sessions/session-XXX.md`.
- Save the untouched source as `sessions/session-XXX-notes.md`.

Prose is retired. Sessions are written up as a record, a fact outline, and a session outline; no chapter follows.

## Status guide

- `raw` — source notes are saved, but the session has not been processed.
- `processed` — a clean session record exists, but it has not been checked against the notes.
- `reviewed` — the record has been checked and open questions are listed.
