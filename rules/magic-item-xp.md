# Magic Item XP

How the table handles experience for magic items. OSE treats this as an optional rule; this campaign uses a house variation of it.

**Source:** OSE Referee's Book, p. 11, "XP For Magic Items (Optional Rule)" and "Selling magic items".  
**Authority:** The DM's ruling governs where it departs from the book. See [the rulings log](rulings-log.md).

## The DM's ruling, as given

Quoted from the referee's Discord post, 2026-10-26:

> "So to confirm about the scrolls. The XP you gain from selling them is independent of the money you get for selling them. So regardless of how much you are selling them for you get the 250 XP.
> I'm getting this from pg 11 in the OSE Referee's book. While I'm not giving XP for simply finding XP, I think it's fair to give the XP if you decide to sell them. But since the monetary value of many magical items is quite high I didn't want to simply give you the gp value in XP since that can quickly spiral out of control.
> This setting is on the lower end of the spectrum magic wise so if you find a buyer for more permanent magical items (rings, swords, armour etc) it would be be quite a lot of gold.
> Scrolls, potions and one shot usable items are more common though."

## What that means in play

| Point | Ruling |
|---|---|
| XP on discovery | None. Finding a magic item pays nothing. |
| XP on sale or trade | Paid, and **separate from the gold received** |
| Amount for a scroll | **250 XP per scroll**, flat, whatever the sale price |
| Amount for other items | Not yet ruled; the book's table below is the starting point |
| Division | Party XP, split as the table does for treasure |

## The book's table, for reference

Values are per item as written. The campaign modifies these; see the ruling above.

| Item | XP |
|---|---:|
| Ammunition | 25 per plus, per piece |
| Chain mail | 600 per plus |
| Leather armour | 300 per plus |
| Miscellaneous item | 2,000 |
| Plate mail | 900 per plus |
| Potion | 250 |
| Protection scroll | 1,000 |
| Ring | 2,000 |
| Rod | 4,000 |
| Shield | 250 per plus |
| **Spell scroll** | **100 per spell level** |
| Staff | 5,000 |
| Sword | 500 per plus |
| Wand | 3,000 |
| Weapon | 500 per plus |

**Selling magic items (book rule):** XP at 1 per gp of sale value. The campaign does not use this for scrolls, and the DM has flagged the gp-per-XP route as one he wants to avoid because magic-item prices spiral.

## Where the campaign departs from the book

1. **No XP for finding.** The book's optional rule pays XP for items gained by adventuring; this table pays only on disposal.
2. **Flat 250 per scroll, not 100 per spell level.** *Bless* is 1st level and *Speak with Animals* is 2nd, so the book's rate would give 100 and 200. The DM's flat 250 is higher for the 1st-level scroll and higher again in total (500 against 300).
3. **Not 1 XP per gp.** Sale price and XP are decoupled, explicitly to stop the gp value driving advancement.

## Worked example — the Session 2 scrolls

| Item | Book value | Campaign value |
|---|---:|---:|
| Scroll of Bless (1st level) | 100 | 250 |
| Scroll of Speak with Animals (2nd level) | 200 | 250 |
| **Total if sold** | **300** | **500** |

Five-way split: 100 XP each before prime requisite bonuses; Elowyn takes 110 with his +10%.
