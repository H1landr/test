# Session Intake Checklist

Use this checklist with the [detailed session template](../templates/session.md).

## Before processing

1. Save the raw notes exactly as supplied in `sessions/session-XXX-notes.md`.
2. Note who wrote the notes and which PC they were playing.
3. Note the real-world date, in-world date, location, and attending PCs.
4. Mark any part of the notes that is uncertain, disputed, or remembered secondhand.

## Create the processed record

1. Copy [the session template](../templates/session.md) to `sessions/session-XXX.md`.
2. Write a five-to-seven-bullet summary.
3. Build the scene chronology in order.
4. Separate confirmed events from rumors and inferences.
5. Record people, places, clues, combat, loot, XP, and rules invoked.
6. List new or advanced threads.
7. Add `[?]` items for anything the notes do not settle.

## Update the rest of the archive

- [ ] Add the session to [the session index](index.md).
- [ ] Update [party roster](../state/party-roster.md), [XP ledger](../state/xp-ledger.md), and [treasure ledger](../state/treasure-ledger.md).
- [ ] Update [threads](../state/threads.md), [rumors](../state/rumors.md), [fronts](../state/fronts.md), and [timeline](../state/timeline.md).
- [ ] Create or revise affected entity pages.
- [ ] Add new names and terms to [the glossary](../state/glossary.md).
- [ ] Record corrections in [the changelog](../state/changelog.md).

## Session outline

- [ ] Build the outline from the record, scene by scene.
- [ ] Give each scene its viewpoint, beats, and order of play; no prose.
- [ ] List the decisions the session needs from the user.

Prose is retired as of 2026-10-27. No chapter follows the outline.
